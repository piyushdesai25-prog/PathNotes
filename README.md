# 🏦 AI Banking Analytics System

An AI-powered Banking Analytics System developed as a college mini/major project. This project combines traditional banking operations with Machine Learning to provide intelligent insights such as loan approval prediction, fraud detection, customer segmentation, and credit score prediction.

---

## 📌 Features

### 👤 User Authentication
- Secure Login
- Role-Based Access (Admin/Employee)

### 👥 Customer Management
- Add Customer
- Update Customer
- Delete Customer
- Search Customer
- View Customer Details

### 🏦 Account Management
- Open New Account
- Close Account
- Freeze / Unfreeze Account
- View Account Details

### 💳 Transaction Management
- Deposit
- Withdraw
- Fund Transfer
- Transaction History
- Search & Filter Transactions

### 💰 Loan Management
- Apply for Loan
- View Loan Status
- Loan History

### 🤖 AI Features
- Loan Approval Prediction
- Customer Segmentation
- Fraud Detection
- Credit Score Prediction

### 📊 Analytics Dashboard
- Total Customers
- Total Accounts
- Total Transactions
- Active Loans
- Fraud Alerts
- Revenue Overview
- Interactive Charts

### 📄 Reports
- Customer Report
- Transaction Report
- Loan Report
- Fraud Report
- Export to PDF / CSV / Excel

# 🤖 AI Modules

## Loan Approval Prediction
Predicts whether a customer is eligible for a loan using Machine Learning.

## Customer Segmentation
Groups customers based on financial behavior using K-Means Clustering.

## Fraud Detection
Detects suspicious banking transactions using anomaly detection techniques.

## Credit Score Prediction
Predicts customer credit score based on financial history.
